# Project Structure

This document describes the intended roles of the project's top-level files. Check the actual files in the current checkout because different project snapshots may contain different modules.

| File | Purpose |
|---|---|
| `main.py` | Main program and application orchestration. |
| `intents.py` | Labeled training phrases and intent labels. |
| `decision_engine.py` | Intent/action routing. |
| `chatbot_engine.py` | Optional Gemini-backed chat integration. |
| `web_search.py` | Web search and result formatting. |
| `task_engine.py` | Restricted arithmetic evaluation. |
| `task_manager.py` | Task operations and JSON persistence. |
| `local_knowledge.py` | Selected offline educational answers. |
| `automation_engine.py` | Constrained note/file action handling. |
| `messaging_engine.py` | Confirmed messaging-draft creation. |
| `voice_assistant.py` | Optional speech input/output. |
| `evaluation.py` | Classifier metrics and evaluation output. |
| `compare_models.py` | Model configuration comparison. |
| `test_*.py` | Automated tests for the modules indicated by each filename. |
| `requirements.txt` | Core Python dependencies. |
| `requirements-voice.txt` | Optional voice dependencies. |
| `.env.example` | Safe template for environment variables. |
| `.gitignore` | Excludes secrets, environments, caches, and local generated data. |
| `PROJECT_REPORT_NOTES.md` | Content guide for the college report. |
| `docs/` | Supporting architecture, setup, testing, and security documentation. |

## Generated or local-only files

Do not commit these unless there is a deliberate, documented reason:

- `.env` — contains local secrets.
- `.venv/` or `venv/` — local Python environment.
- `__pycache__/` and `*.pyc` — generated bytecode.
- `tasks.json` — local user task data.
- `output/` — generated notes or runtime output, if created.
- IDE-specific files unless the team intentionally shares them.
