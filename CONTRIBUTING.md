# Contributing

This is an educational project. Before proposing changes:

1. Read the root `README.md` and relevant documents under `docs/`.
2. Keep changes focused and explain their purpose.
3. Do not commit `.env`, API keys, personal task data, virtual environments, or generated files.
4. Add or update tests when changing behavior.
5. Run the relevant tests and report actual results.
6. Update documentation whenever commands, dependencies, configuration, or behavior changes.
7. Never claim an integration test passed if it was skipped or failed.
